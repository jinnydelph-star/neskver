# (Не)скверное место

Экологическая тропа по зелёным местам МО Большая Охта Красногвардейского района Санкт-Петербурга. Проект разработан в детской библиотеке № 4 ЦБС Красногвардейского района в 2026 году.

**[Открыть сайт](https://jinnydelph-star.github.io/neskver/)**

## Что есть на сайте

- Описание проекта и маршрута по Большой Охте.
- Иллюстрированная карта скверов и достопримечательностей.
- Раскрывающиеся карточки мест: история, растения, интересные факты и фотографии.
- Галерея детских рисунков с разделами «Растения» и «Здания» и информацией об авторах.
- Контакты и режим работы детской библиотеки № 4.

## Локальный запуск

Нужны Node.js 22 и npm.

```sh
npm ci
npm run dev
```

Сайт откроется по адресу http://localhost:5180/.

## Сборка

```sh
npm run build
npm run preview
```

Готовые файлы находятся в `dist/`.

## Публикация

Сайт размещён на GitHub Pages. После отправки коммитов в ветку `samoupravstvo` процесс `Publish website` автоматически собирает и публикует обновление. Статус доступен во вкладке [Actions](https://github.com/jinnydelph-star/neskver/actions).

Для GitHub Pages сборка использует базовый путь `/neskver/`; скрипт `scripts/prepare-pages.mjs` подготавливает пути к рисункам и шрифтам.

## Устройство проекта

- `src/components/` — разделы сайта и карточки мест.
- `src/style.css` — общие стили, цвета и шрифты.
- `public/assets/` — иллюстрации, фотографии и значки.
- `public/fonts/` — шрифты проекта.
- `.github/workflows/pages.yml` — автоматическая публикация.

Сайт создан на Vue 3, Vite и Tailwind CSS.
